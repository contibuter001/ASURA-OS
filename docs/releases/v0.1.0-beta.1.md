# ASURA OS 0.1.0-beta.1

The first ASURA OS release: a Void Linux (glibc, runit) system with the
Hyprland compositor and end-4's Quickshell desktop, set up and kept up to date
by ASURA's own tools. It is a beta: install it on a machine you can afford to
wipe.

## Get it

1. Download `asura-os-0.1.0-beta.1-x86_64.iso` and `SHA256SUMS` below.
2. Check it: `sha256sum -c SHA256SUMS` must print `OK`.
3. Write it to a USB stick (see the README), boot it with **Secure Boot
   turned off**, and open **Install Asura OS**.

## What is in it

- **The desktop:** end-4's desktop with ASURA's layout: a plain top bar, a
  bottom dock that hides while you work, a control centre, the overview and
  launcher, colours from your wallpaper.
- **Updates that do not break:** `asura update` installs the newest ASURA
  whose CI passed, takes a Btrfs snapshot before system updates, and refreshes
  the running desktop without a logout. `asura rollback` goes back.
- **One-time fixes** (`asura migrate`) reach installed machines automatically.
- **Snapshots:** taken before system updates and package installs;
  `asura snapshot` lists them with their date, reason and ASURA version, and
  `sudo asura rollback --system NAME` boots one.
- **Optional services:** `asura enable docker` (also bluetooth, printing, ssh,
  libvirt, tailscale) installs, starts and sets up a service in one command.
- **Faster downloads:** the installer picks the quickest Void mirror;
  `asura mirror fastest` does it again later.
- **Help that knows the system:** OpenCode is installed with ASURA's skills,
  and `asura doctor` (or `asura doctor --json`) checks the whole machine.
- **A firewall** (incoming connections blocked) and a boot splash, on by
  default.

## Known issues

- **Secure Boot is not supported.** Turn it off in the firmware to boot the
  ISO and the installed system.
- **Hyprland 0.49** (prebuilt, from a third-party Void repository). A newer
  Hyprland built by ASURA comes after the beta.
- **Updates come from the `dev-unstable` branch** through `asura update`.
  ASURA's signed package repository is built but not yet published.
- **Installs through the Store take no snapshot yet;** installs through ASURA's
  own tools do.
- **Checksums are signed only if the release key is set up**; otherwise verify
  with `SHA256SUMS` alone.

## Report a problem

Open an issue with the output of `asura version -v` and `asura doctor --json`,
and `~/.local/state/asura/quickshell.log` for desktop problems. A hardware
profile (`asura hardware report --profile`) helps the most.
